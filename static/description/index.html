📍 Panamá - Distritos (cabeceras de distrito)

l10n_pa_districts carga los 83 distritos oficiales de la República de Panamá como registros del modelo estándar res.city, asociados a su provincia o comarca correspondiente (res.country.state cargado por l10n_pa_provinces) y al país Panamá (base.pa).

En Panamá, el equivalente administrativo de "ciudad/municipio" es el distrito. Este módulo renombra la etiqueta "Ciudad" a "Distrito" mediante i18n/es.po, manteniendo compatibilidad total con los flujos estándar de Odoo (direcciones en Contactos, Empresa, ventas y facturación).

✅ Características

  • ✓ 83 distritos oficiales cargados como res.city.
  • ✓ Cada distrito asociado a su provincia o comarca.
  • ✓ País Panamá (base.pa) en cada registro.
  • ✓ Etiqueta "Ciudad" → "Distrito" en español.
  • ✓ Depende de l10n_pa_provinces (forzado).
  • ✓ Visible en formularios de Contacto y Empresa.
  • ✓ Compatible con cualquier módulo que use res.city.
  • ✓ Actualizable con -u l10n_pa_districts.

⬇️ Instalación

Requisito: este módulo depende de l10n_pa_provinces. Odoo no permitirá instalar l10n_pa_districts sin antes instalar el módulo de provincias.
  1. Asegúrese de tener instalado l10n_pa_provinces.
  2. Copie la carpeta l10n_pa_districts dentro de su directorio de addons.
  3. Reinicie Odoo o actualice la lista de módulos desde Ajustes → Técnico → Módulos locales.
  4. Instale el módulo Panamá - Distritos.
  5. Vaya a Contactos → Configuración → País: Panamá → Ciudades/Distritos.

Si la base ya estaba creada, ejecute -u l10n_pa_districts al iniciar Odoo para forzar la carga del CSV.
